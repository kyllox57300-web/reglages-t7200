Réglages Epson SureColor T7200

Choisis le support chargé dans la machine : la fiche te donne, dans l'ordre, ce qu'il faut régler sur l'imprimante, dans le pilote Windows et dans ton fichier.

Imprimer une affiche A4 en A0

Une seule fois sur ton PC

  1. Télécharge les deux réglages :bache.ssf   adhesif.ssf
  2. Ouvre un PDF dans Acrobat, puis Fichier → Imprimer → Propriétés.
  3. Clique sur Enregistrer/supprimer… → Importer… et choisis bache.ssf. Recommence avec adhesif.ssf.Les réglages « bache » et « adhesif » apparaissent dans la liste. Ferme avec Annuler.

À chaque impression

  1. Regarde quel rouleau est chargé dans la machine : bâche ou adhésif.Le réglage choisi doit correspondre au rouleau, sinon le message « Support ne correspond pas » apparaît.
  2. Dans Acrobat : Fichier → Imprimer → Propriétés.
  3. Paramètre de sélection : bache ou adhesif, puis OK.
  4. Dans la fenêtre d'Acrobat, choisis Ajuster.Ne coche pas « Choisir la source du papier selon le format de page PDF ».
  5. Clique sur Imprimer.L'affiche sort en A0 (841 × 1189 mm). Coupe la bande blanche sur le côté. Sur l'adhésif, ne touche pas le tirage pendant 30 minutes.

Pour ne rien ressaisir : une fois les réglages faits dans le pilote, clique sur Enregistrer/supprimer… en haut de l'onglet Principal et donne-leur le nom du support (ex. « Bâche intissée »). La prochaine fois, choisis-le dans Paramètre de sélection. Depuis la même fenêtre, Exporter crée un fichier que tes collègues peuvent Importer sur leur poste.
