IMPRESSION AUTOMATIQUE - EPSON SURECOLOR T7200
==============================================

Le principe : on glisse un PDF dans le dossier du papier chargé
(Bache intissee, Adhesif mat, Adhesif brillant) et il s'imprime tout seul
avec les bons réglages.


CE QU'IL FAUT
-------------
- Un accès administrateur au serveur Windows où l'imprimante PRT29 est installée.
- SumatraPDF portable 64 bits (gratuit) : https://www.sumatrapdfreader.org
  Renommer le fichier téléchargé en SumatraPDF.exe.


INSTALLATION (une seule fois, sur le serveur)
---------------------------------------------
1. Copier ce dossier sur le serveur, avec SumatraPDF.exe dedans.

2. Ouvrir PowerShell EN ADMINISTRATEUR dans ce dossier, puis lancer :

     powershell -ExecutionPolicy Bypass -File .\installer.ps1

   Si l'imprimante ne s'appelle pas PRT29 sur le serveur, le script
   affiche la liste des imprimantes. Relancer alors avec le bon nom :

     powershell -ExecutionPolicy Bypass -File .\installer.ps1 -ImprimanteSource "Nom exact"

3. ÉTAPE IMPORTANTE : régler chaque file d'impression.
   Panneau de configuration > Périphériques et imprimantes
   > clic droit sur "T7200 - Bache intissee" > Propriétés de l'imprimante
   > onglet Avancé > bouton "Valeurs par défaut..."
   Mettre les réglages de la fiche :
   https://kyllox57300-web.github.io/reglages-t7200/
   (Support, Largeur du rouleau, Qualité maximale, Vitesse rapide décochée,
   Détails plus fins coché, et COCHER "Ajuster à la largeur du papier rouleau"
   pour que n'importe quel PDF prenne la largeur du rouleau.)
   Refaire la même chose pour les autres files.

4. Test : copier un petit PDF dans
     C:\ImpressionT7200\Depot\Bache intissee
   Au bout de 10 secondes environ, il doit s'imprimer puis passer dans
     C:\ImpressionT7200\Imprimes\Bache intissee


POUR LES COLLÈGUES
------------------
Ouvrir dans l'explorateur :   \\NOM-DU-SERVEUR\ImpressionT7200
(Clic droit sur le dossier > Envoyer vers > Bureau, pour un raccourci.)

Glisser le PDF dans le dossier du papier qui est CHARGÉ dans la machine.
C'est tout.


EN CAS DE SOUCI
---------------
- Journal :  C:\ImpressionT7200\journal.txt
- Un PDF qui n'a pas pu être imprimé part dans C:\ImpressionT7200\Erreurs
- Message "Support ne correspond pas" : le rouleau chargé n'est pas celui
  du dossier utilisé. Changer de dossier ou de rouleau.
- PDF mal dimensionné : dans C:\ImpressionT7200\surveiller.ps1, remplacer
  $Echelle = "fit"  par  $Echelle = "noscale", puis redémarrer la tâche
  (Planificateur de tâches > "Impression T7200" > Terminer puis Exécuter).


AJOUTER UN PAPIER
-----------------
1. Ajouter une ligne dans C:\ImpressionT7200\papiers.csv
   (nom du dossier;nom de la file)
2. Relancer installer.ps1 (il ne recrée pas ce qui existe déjà).
3. Régler les "Valeurs par défaut" de la nouvelle file (étape 3).


DÉSINSTALLER
------------
En administrateur :
  Unregister-ScheduledTask -TaskName "Impression T7200" -Confirm:$false
  Remove-SmbShare -Name ImpressionT7200 -Force
  Remove-Printer -Name "T7200 - Bache intissee"   (idem pour les autres)
Puis supprimer C:\ImpressionT7200
