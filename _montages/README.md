# Montages TikTok : Brico Cash Fameck

Les pubs vidéo du magasin, montées avec Claude Code.

1. **Dépose tes rushs** (photos, vidéos) dans `_montages/rushs/AAAA-MM-sujet/`.
   Sur GitHub : *Add file → Upload files* (25 Mo maximum par fichier). Sur iPhone, choisis les vidéos depuis l'app **Fichiers**
   (pas la Photothèque) pour garder la qualité d'origine.
2. **Demande le montage à Claude** (ex. : « Monte une pub TikTok avec les rushs de `rushs/2026-12-noel/` »).
   Les règles sont dans `CLAUDE.md` : Claude les suit à chaque fois.
3. **Récupère les vidéos finies** dans `_montages/exports/AAAA-MM-sujet/` (avec et sans musique).

⚠️ Le dépôt est public : n'y mets que ce qui pourrait passer sur TikTok (pas de documents internes, pas de clients reconnaissables).

Dossiers : `rushs/` · `musiques/` (libres de droits) · `logo/` · `exports/` · `polices/` · `outils/`.
